### 🌟 Project Overview
Day 4 focused on the concept of **stochasticity** and structured data. The primary project, **Rock Paper Scissors**, uses randomization to simulate a game against an AI, while the supporting scripts explore the depth of Python's list capabilities.

### 🧠 Skills Mastered
* **The Random Module:** Utilizing `import random` with `randint()` and `choice()` for non-deterministic code.
* **Data Structures (Lists):** Creating, accessing, and modifying ordered collections of data.
* **Nested Lists:** Mastering "lists within lists" to represent 2D data structures (e.g., the "Dirty Dozen" logic).
* **Index-Based Retrieval:** Accessing specific data points using double indexing (e.g., `list[row][column]`).
* **Validation Logic:** Implementing boundary checks to ensure user inputs don't cause `IndexErrors`.

---

### 🏆 Main Project: Rock Paper Scissors
An interactive CLI game that pits the user against the computer's RNG (Random Number Generator).
* **Key Feature:** Uses a list to store ASCII art constants, which are then rendered based on the index selected by the user or the computer.
* **Logic Gauntlet:** Accounts for all win/loss/draw scenarios and handles invalid user inputs gracefully to prevent script crashes.

---

### 🧪 Randomization & List Lab
In addition to the main game, I developed several focused scripts to explore data organization:
* **The Dirty Dozen:** An exploration of nested lists where I grouped categories (fruits and vegetables) into a single multidimensional list and practiced retrieving nested elements.
* **Who Will Pay The Bill:** A utility script that picks a random person from a list, demonstrating the power of `random.choice()`.
* **Heads or Tails:** A binary decision-making tool using random integers and the Modulo operator.

> "A list is more than just a collection; it is the first step toward managing structured data effectively."
