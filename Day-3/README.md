### 🌟 Project Overview
Day 3 was dedicated to mastering **Control Flow**. The main deliverable is **Treasure Island**, a complex text-based adventure game. To build it, I developed a series of micro-projects to master conditional logic, nesting, and multiple logical operators.

### 🧠 Skills Mastered
* **Complex Conditionals:** Utilizing `if`, `elif`, and `else` to create branching paths.
* **Nested Logic:** Layering checks within checks (as seen in the Rollercoaster Ticket system).
* **Logical Operators:** Implementing `and`, `or`, and `not` to evaluate multiple criteria at once.
* **Input Normalization:** Using methods like `.lower()` to ensure user input remains consistent and error-free.
* **Arithmetic Integration:** Combining math with logic (e.g., Modulo operator for Even/Odd checks).

---

### 🏆 Main Project: Treasure Island
A "Choose Your Own Adventure" game that uses a deep decision tree.
* **Key Feature:** Extensive use of nested `if` statements.
* **Logic:** The player must navigate through a lake and a series of colored doors. Only the correct logical sequence leads to victory; all other paths trigger specific "Game Over" states.

---

### 🧪 The Logic Lab (Supporting Scripts)
Alongside the main project, I developed several focused scripts to refine my logic:
* **Rollercoaster Ticket System (v1.0 - v4.0):** An evolving script that handles height requirements, age-based pricing, photo add-ons, and even "mid-life crisis" discounts (ages 45-55).
* **Pizza Delivery Program:** A small-scale POS system calculating bills based on size, toppings, and extra cheese using multiple `if` conditions.
* **BMI Calculator 2.0:** An upgrade from Day 2 that interprets numerical results into health categories.
* **Even/Odd Identifier:** A fundamental logic check using the Modulo (`%`) operator.

> "Code is like a map; Control Flow determines which path the data takes to reach its destination."
