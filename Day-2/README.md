### 🌟 Project Overview
The **Tip Calculator** is a practical utility script that automates the arithmetic behind splitting a bill. This project marks a significant step forward in my "100 Days of Code" journey, moving from simple string handling to managing diverse data types and performing precise mathematical calculations.

### 🧠 Skills Mastered
* **Data Type Manipulation:** Understanding the distinction between Strings, Integers, and Floats, and mastering how to convert between them through Type Casting.
* **Mathematical Operators:** Implementing calculation logic for accurate results, including multiplication for percentages and division for splitting totals.
* **Number Formatting:** Utilizing f-strings and the `round()` function to ensure numerical output is displayed clearly and correctly to two decimal places.
* **Dynamic Arithmetic:** Creating a cohesive workflow that calculates a tip percentage, adds it to a base bill, and distributes the total among a variable number of people.

---

### 🛠️ How it Works
1.  **Input Collection:** Captures the total bill amount, the desired tip percentage, and the number of participants.
2.  **Percentage Calculation:** Converts the tip into a decimal format to determine the total tip amount.
3.  **Summation Logic:** Adds the tip to the initial bill to find the grand total.
4.  **Distribution:** Divides the grand total by the number of people to find the individual share.
5.  **Formatted Output:** Returns the final amount each person owes, rounded for financial accuracy.

> "Clean code is not just about logic; it's about making data readable and actionable for the end-user."
