### 🌟 Project Overview
Day 5 focused on the power of **Iteration**. The primary project, **PyPassword Generator**, is a tool that automates the creation of complex, randomized security strings. To build this, I mastered `for` loops and the `range()` function, allowing me to process sequences of data with minimal code.

### 🧠 Skills Mastered
* **For Loops:** Iterating over lists and ranges to perform repetitive tasks efficiently.
* **Range Function:** Generating sequences of numbers for controlled loop execution.
* **Accumulator Pattern:** Using variables to track sums or build strings/lists across multiple iterations.
* **List Shuffling:** Using `random.shuffle()` to increase entropy and ensure non-predictable outputs.
* **Logic Integration:** Combining loops with mathematical logic to solve classic programming puzzles.

---

### 🏆 Main Project: PyPassword Generator
A robust security utility that generates high-entropy passwords based on user-defined complexity.
* **Logic:** The script collects the desired number of letters, symbols, and numbers, stores them in a list, and then utilizes a loop-driven shuffle to randomize the order.
* **Complexity:** Moves beyond simple concatenation to "Hard Level" randomization, ensuring the password does not follow a predictable pattern (e.g., letters followed by numbers).

### 🧪 The Iteration Lab (Supporting Scripts)
Alongside the main project, I built these scripts to master loop-based logic:
* **FizzBuzz Game:** A classic coding interview challenge using loops and modulo operators to print specific strings based on divisibility by 3 and 5.
* **Gauss Challenge:** An automation of the famous sum calculation from 1 to 100 using the `range()` function.
* **Custom Max/Sum Functions:** Recreating Python's built-in `max()` and `sum()` logic from scratch using loops to understand the underlying mechanics of data processing.

> "A single loop can process a million lines of data as easily as ten."
